# MD Studio

XML 태그 색상 구분, 태그 균형 검사, 지속 검색 하이라이트, 미리보기 메모, 계층형 목차(TOC) 미니맵 & 양방향 점멸 플래시 네비게이션, 순수 HTML5 무결 렌더러 및 픽셀 정합 에디터를 지원하는 단일 파일 마크다운 에디터

- **버전**: 1.7.0
- **라이브 URL**: [https://okjoizj-org.github.io/md-studio/](https://okjoizj-org.github.io/md-studio/)

## 주요 기능
- **적응형 계층 목차 & 1:1 동기화 미니맵 (Hierarchical TOC & Exact Scrollspy)**: 문서 내 최소 헤딩 레벨을 기준으로 상대적 깊이(0~3+단계)를 자동 계산하여 시각적 위계(들여쓰기·글꼴 굵기·가지선)를 선명하게 표현하고, 우측 미니맵 눈금선과 목차 팝오버의 활성 항목(`active`) 위치를 100% 일치시켜 동기화
- **양방향 점멸 플래시 네비게이션 (Dual-Pane Flash Jump)**: 목차 아이템 또는 미니맵 눈금선 클릭 시 미리보기와 에디터 양쪽 모두 해당 위치로 부드럽게 스크롤되며, Ctrl+F 스타일의 파란색 점멸 하이라이트(`.flash-preview-heading`, `.flash-line`)를 동시에 발생시켜 위치 즉각 식별
- **블록 레벨 순수 HTML 완전 격리 엔진 (Zero-Indented-Code-Block Interference)**: 마크다운 엔진의 4칸 스페이스 들여쓰기 코드블록 변조 및 살균(Sanitizer) 난도질을 완전히 차단하여 스마트폰 위젯, 다중 그라데이션, `clip-path`, 아코디언 `<details>`, `backdrop-filter` 등 고난도 컴포넌트를 브라우저 순정 100% 원형 그대로 온전히 렌더링
- **에디터 커서 & 드래그 선택 영역 완전 정합 (Selection Alignment)**: 고정폭 폰트 메트릭 통일, 하이라이트 레이어 0px 너비 고정, 스크롤바 폭 실시간 동적 보정으로 텍스트와 드래그 영역의 어긋남 원천 차단
- **마이크로 툴팁 시스템**: Emil Kowalski 디자인 철학 기반의 부드러운 스프링 모션, 연속 호버 지연 스킵 및 단축키 배지가 적용된 커스텀 툴팁
- **XML 태그 색상 구분 & 태그 균형 검사**: 태그 구조 파악 및 짝 맞춤 검사 지원
- **지속 검색 하이라이트**: Ctrl+F 검색 시 에디터와 미리보기에 검색 결과 지속 표시 및 이전/다음 이동
- **미리보기 메모**: 미리보기 영역에서 텍스트 드래그 시 메모 생성, 이동 및 삭제 지원
- **다크 모드**: 라이트/다크 테마 전환 지원
- **단일 파일 실행**: 외부 의존성이나 CDN 없이 독립적으로 동작하는 단일 HTML 파일
